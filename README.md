I am a **Senior Software Engineer & Distributed Systems Architect** with **7+ years of experience** engineering enterprise SaaS platforms, high-throughput streaming services, and production observability systems across scale-intensive environments (**SolarWinds**, **Walmart Global Tech**, and **Zoho**).
